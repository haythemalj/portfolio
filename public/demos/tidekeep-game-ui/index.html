Tidekeep

A mobile game UI kit for an original island puzzle game. Four core screens and the button system behind them, designed and coded as working HTML and CSS. Tap the buttons, tabs and the replay control to see the interaction states.

Game UI concept by Haythem Aljane, 2026

Button system

Every action uses the same chunky button: a thick outline, a highlight on top and a solid base underneath. Pressing it drops the button onto its base, so the player feels the tap.
